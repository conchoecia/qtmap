4. Install synthetic reference into OPFS

Writes the same shard set into /qtqc-mm2browser/references/synth/ in the Origin Private File System using the async createWritable API. After install, Section 5 will read the shards back via dedicated-worker FileSystemSyncAccessHandle for the OPFS read microbenchmark.

5. OPFS read microbenchmark

Runs 1000 random explicit-offset reads against the installed shards at three granularities: 12 B (one hit record), 4 KB, 64 KB. Reports MiB/s per granularity. The Phase 1 gate: Chrome must come within ~2× of Firefox at 12 B granularity to keep the current shard layout, otherwise bulk-shard reads.
